# Release v1.0.0

Initial reproducibility release accompanying the Tomography HCC MRI segmentation manuscript.

The release contains:

- audited Dataset801 ATLAS configuration and patient-level five-fold split;
- OpenSwissHCC registration and HCC-only reference-reconstruction code;
- fixed Dataset804 and Dataset805 configurations and folds;
- primary OOF case-level metrics;
- paired venous-only versus arterial+venous analysis;
- all-132-subject external OpenSwissHCC analysis;
- tumour-negative false-positive safety analysis;
- lesion-matching sensitivity analyses;
- lesion-size and multiplicity analyses;
- complete six-pair phase comparison;
- ATLAS/Karabağ protocol reconciliation;
- primary trained checkpoints supplied as separate archives.

Raw medical images are not redistributed.
